# HWID Spoofer

Консольна утиліта на C++ для Windows, яка підміняє ідентифікатори машини: ім'я ПК, `MachineGuid`, `ProductId`, дату встановлення, MAC-адреси мережевих адаптерів, часовий пояс, локаль і роздільну здатність екрана. Перед змінами робить бекап, тож усе можна повернути назад.

> ⚠️ Програма змінює системний реєстр і налаштування мережевих адаптерів. Використовуй лише на своєму ПК і на власний ризик. Обхід античитів чи банів може порушувати правила сервісів (ToS).

## Що змінюється

| Параметр | Де в системі | Як |
|---|---|---|
| Ім'я комп'ютера | `HKLM\SYSTEM\...\ComputerName` (і `ActiveComputerName`) | випадкове `DESKTOP-XXXXXXX` |
| MachineGuid | `HKLM\SOFTWARE\Microsoft\Cryptography` | новий GUID |
| ProductId | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion` | випадковий у форматі Windows |
| InstallDate | там само | випадкова дата в діапазоні 2018–2023 |
| MAC-адреси | `NetworkAddress` у класі мережевих адаптерів | випадкова локально-адміністрована MAC |
| Часовий пояс | `SetDynamicTimeZoneInformation` | зі списку або випадковий |
| Локаль | налаштування регіону користувача | зі списку або випадкова |
| Роздільна здатність | `ChangeDisplaySettings` | зі списку (якщо монітор підтримує) |

Випадкові значення генеруються криптостійким генератором (`CryptGenRandom`).

## Режими

Запуск без аргументів відкриває інтерактивне меню:

1. **Stable**: зміни постійні, поточні значення зберігаються в `backup.dat`.
2. **Temporary**: зміни діють, доки не натиснеш Enter, після чого все повертається.
3. **Check**: тільки показати поточні значення.
4. **Reset**: повернути значення з `backup.dat`, а якщо його немає — стандартні значення Windows.

Для часового поясу, локалі й роздільної здатності можна вибрати пункт зі списку або `0`, щоб узяти випадковий.

### Аргументи командного рядка

```
spoof.exe               інтерактивне меню
spoof.exe --check       лише перевірити поточні значення
spoof.exe --mode 1      stable, без меню, усе випадкове
spoof.exe --mode 2      temporary, без меню, усе випадкове
spoof.exe --restore     відновити з backup.dat
spoof.exe --restore <f> відновити з іншого файлу
spoof.exe --reset       скинути до стандартних значень Windows
```

Після кожної дії запускається чекер: він перечитує реєстр і показує, що застосувалось (`[OK]`), а що ні (`[!!]`). Усі дії пишуться в `spoof_log.txt`.

## Збірка

Потрібен MinGW-w64 (наприклад, через MSYS2), щоб `g++` і `windres` були в `PATH`.

```bat
build.bat
```

Що робить скрипт:

```bat
windres resource.rc -O coff -o resource.o
g++ spoof.cpp resource.o -o spoof.exe -lrpcrt4 -liphlpapi -static-libgcc -static-libstdc++ -static -std=c++17 -O2
```

`app.manifest` вшиває в exe вимогу прав адміністратора, тож UAC з'являється автоматично.

## Запуск разом зі Steam

`launch.bat` у фоні запускає `launch.ps1`. Той стартує `spoof.exe` з правами адміністратора, чекає завершення і потім відкриває Steam від звичайного користувача. Шлях до Steam задано в `launch.ps1`.

## Файли

```
spoof.cpp      основний код (v4)
spoof.c++      ранній прототип (лише ім'я ПК і GUID)
resource.rc    підключення маніфесту
app.manifest   requireAdministrator
build.bat      збірка
launch.bat     тихий запуск через PowerShell
launch.ps1     spoof.exe (admin) → Steam
```

`backup.dat`, `spoof_log.txt` і зібраний `spoof.exe` у репозиторій не потрапляють: у бекапі лежать справжні ідентифікатори твоєї машини.

## Обмеження

- Потрібні права адміністратора.
- Змінити ім'я ПК й MAC повністю вдасться лише після перезавантаження або перепідключення адаптера.
- Серійні номери заліза (диск, материнська плата, SMBIOS) на рівні драйверів **не** змінюються.
